Guía de demo por Historias de Usuario

KinePro - Grupo B

Recorrido sugerido para mostrar las funcionalidades implementadas hasta el momento: cuentas, perfiles, gestión de personal, pacientes, auditoría y QR.

Idea general: conviene demo por HU, no por pantalla. Para cada historia, mostrar un caso correcto y, si hay tiempo, un caso fallido importante.

Preparación antes de la demo

  • Tener el backend y frontend levantados.
  • Tener una cuenta secretaria o administrativa para la parte de gestión.
  • Tener una cuenta paciente para mostrar inicio, perfil y QR.
  • Tener abierto el correo de prueba para recuperación de contraseña.
  • Preparar un DNI nuevo y un email nuevo para registrar usuarios sin errores.
  • Preparar un DNI ya existente para mostrar validaciones.

Gestión de cuentas y perfiles

HU: Registrar usuario

Qué mostrar

  • Registro correcto de un paciente.
  • Validación por DNI existente.
  • Validación por email inválido.
  • Validación de fecha de nacimiento y teléfono si se quiere sumar detalle.
Frase para explicar: En nuestro flujo actual, la cuenta se crea con contraseña temporal igual al DNI. Luego el usuario puede cambiarla desde su perfil o recuperar contraseña por email.
HU: Iniciar sesión

Qué mostrar

  • Login correcto con DNI y contraseña.
  • Login fallido por contraseña incorrecta.
  • Checkbox de mantener sesión iniciada.
Cierre: Mostrar que al iniciar sesión se accede a la aplicación según el rol del usuario.
HU: Cerrar sesión

Qué mostrar

  • Ingresar con una cuenta.
  • Abrir el menú de usuario.
  • Presionar cerrar sesión.
  • Confirmar que vuelve al login.
HU: Recuperar contraseña

Qué mostrar

  • Entrar a "Olvidaste tu contraseña".
  • Ingresar un email registrado.
  • Mostrar el email recibido con el botón de recuperación.
  • Abrir el enlace y cargar una nueva contraseña.
  • Mostrar redirección automática al login.

Caso fallido sugerido

  • Ingresar una contraseña menor a 8 caracteres.
  • Ingresar una contraseña igual a la anterior.
HU: Cambiar contraseña

Qué mostrar

  • Entrar a Perfil.
  • Seleccionar la sección Seguridad.
  • Cambiar contraseña con datos válidos.

Caso fallido sugerido

  • Nueva contraseña menor a 8 caracteres.
  • Nueva contraseña igual a la anterior.
HU: Ver datos personales

Qué mostrar

  • Entrar a Perfil.
  • Seleccionar Datos personales.
  • Mostrar nombre, apellido, DNI, email, teléfono, obra social, fecha de nacimiento y rol.
HU: Editar datos personales

Qué mostrar

  • Presionar Editar datos.
  • Mostrar que nombre, apellido, DNI y fecha de nacimiento están bloqueados.
  • Editar email, teléfono u obra social.
  • Guardar cambios.

Caso fallido sugerido

  • Intentar guardar un email con formato inválido.

Pacientes y personal

HU: Registrar cuenta de personal / paciente

Qué mostrar

  • Entrar como secretaria o administrativo.
  • Ir a Gestión del personal o Pacientes.
  • Registrar un nuevo miembro o paciente.
  • Mostrar selector de rol.
  • Si el rol es profesional, mostrar campos extra de profesional.

Caso fallido sugerido

  • Registrar con DNI existente.
  • Registrar con email inválido.
HU: Listar plantel

Qué mostrar

  • Listado de personal.
  • Buscador.
  • Filtros por rol: profesionales, secretarias, administrativos.
  • Acciones por miembro.
HU: Crear profesional

Qué mostrar

  • Registrar miembro.
  • Seleccionar rol Profesional.
  • Completar matrícula, especialidad, área de tratamiento, horario de entrada y salida.
  • Confirmar creación.
HU: Editar profesional

Qué mostrar

  • Abrir acciones de un profesional.
  • Seleccionar Editar.
  • Modificar datos permitidos.
  • Mostrar que la matrícula no se puede editar.
HU: Crear / Editar secretaria

Qué mostrar

  • Crear una secretaria desde Registrar miembro.
  • Editar email, teléfono u obra social.
  • Mostrar que los campos bloqueados quedan en gris.
HU: Eliminar profesional / secretaria

Qué mostrar

  • Abrir acciones.
  • Seleccionar Dar de baja.
  • Mostrar modal de confirmación.
  • Confirmar baja y ver que desaparece del listado.
Aclaración: Para testing se implementó eliminación directa. En producción podría pasarse a baja lógica.
HU: Consultar auditoría

Qué mostrar

  • Entrar a Gestión del personal.
  • Cambiar a la sección Auditoría.
  • Mostrar registros de acciones realizadas.
  • Filtrar por acción.
  • Filtrar por fecha, sin permitir fechas futuras.
Dato para mencionar: La auditoría muestra quién realizó la operación, por ejemplo: secretaria · DNI.

Acreditación por QR

HU: Acreditar acceso por QR

Qué mostrar

  • Ingresar como paciente.
  • Ir a Inicio.
  • Presionar Escanear QR.
  • Mostrar apertura de cámara y botón Reintentar.
Aclaración para la demo: Esta parte ya tiene preparado el flujo visual y de cámara. La conexión final con turnos reales queda para cuando esté lista la grilla de horarios.

Orden recomendado para presentar

  1. Registro, login y cerrar sesión.
  2. Recuperación y cambio de contraseña.
  3. Perfil: ver y editar datos personales.
  4. Gestión de personal: listar, crear, editar y dar de baja.
  5. Gestión de pacientes: listar, buscar, registrar y editar.
  6. Auditoría: registros y filtros.
  7. QR de asistencia desde Inicio del paciente.
