# FrontEnd

Frontend del sistema KinePro.

Stack previsto:

- React
- Vite
- TailwindCSS
- Supabase client

La carpeta `src/` contiene la aplicacion. El objetivo es separar por responsabilidades para que el equipo pueda trabajar en paralelo.

## Instalacion inicial

Instalar dependencias:

```bash
npm install
```

Levantar entorno de desarrollo:

```bash
npm run dev
```

Generar build:

```bash
npm run build
```
